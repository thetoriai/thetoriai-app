APP PURPOSE:
This app generates stories, images, and videos using character identity locking.

CORE IDEA:
Characters have DNA (description).
That DNA is reused across image → scene → video.

MAIN FLOWS:

1. CHARACTER
- Upload image
- generateCharacterDescription
- stores description (DNA)

2. IMAGE
- generateSingleImage → creates scene
- editImage → modifies scene

3. STORY
- generateStructuredStory → creates full story
- generateScenesFromNarrative → splits into scenes

4. VIDEO
- generateVideoFromScene
  - parsePerformance → gets speaker/dialogue
  - enhanceCinematicPrompt → improves visuals
  - builds fullPrompt
  - sends to backend

5. AUDIO
- generateSpeech → voice generation
